# 🤖 AI Resume Screening System

## 📌 Overview
An intelligent resume screening system that automatically extracts text from resumes, matches candidate skills using NLP, and ranks candidates based on match percentage.

## ✨ Features
- 📄 Extract text from PDF and DOCX resumes
- 🧹 NLP preprocessing (tokenization, stopwords removal, stemming)
- 🎯 Skill matching and scoring
- 🏆 Candidate ranking
- 🖥️ Graphical User Interface (Tkinter)
- 📊 Export results to CSV

## 🛠️ Technologies
- Python 3.x
- PyPDF2 (PDF extraction)
- python-docx (DOCX extraction)
- pandas (CSV export)
- Tkinter (GUI)
